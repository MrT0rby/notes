## Week 1 - History
- One writing system can be used by many languages
- Cuneiform looks weird
- The Epic of Gilgamesh was epic
## Week 2 - Bits and Bytes
- Binary uses only two digits: 0 and 1.
- Hexadecimal uses digits 0-9 and letters A-F to represent values.
- ASCII represents characters with numeric codes, such as 65 for A.
## Week 3 - Text Structure
- Markdown supports headings, lists, links, and bold text.
- Escape characters allow special symbols to appear as ordinary text.
- UTF-8 uses one to four bytes to encode a Unicode code point.
## Week 4 - Keyboards and Editors
- Ctrl, Shift, and Alt modify the actions of other keys.
- Text editors such as VS Code help programmers write and edit code.
- Search and replace tools make it easier to update repeated text.
## Week 5 - Command Line Interfaces
- A command line interface lets users interact with a computer by typing commands.
- The cp command copies files, while mv moves or renames them.
- Shell scripts automate tasks by running sequences of commands.
